# Portfolio · Agustín Buffa

Static site for GitHub Pages: plain HTML + CSS, no build step.

- `index.html`: all content. Sections have anchors to link per application:
  `#flight-physics`, `#cfd`, `#space`, `#teaching`, `#personal`, `#publications`, `#contact`.
  Individual projects too: `#morphair`, `#llt`, `#morphing-cfd`, `#icing`, `#savonius`, `#cubesat-release`, `#cansat`, `#lia`.
- `assets/style.css`: design (light/dark automatic).
- `assets/img/`: photos. Replace each `<div class="ph">…</div>` with `<img src="assets/img/x.jpg" alt="…">`.
- `assets/Agustin_Buffa_CV.pdf`: CV behind the "Download CV" button.
- Text marked `class="todo"` is a placeholder (shown in orange): fill it in and remove the class.

Preview locally: open `index.html` in the browser, or use the VS Code "Live Server" extension.
